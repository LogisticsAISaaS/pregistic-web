# pregistic.com

Static site for Pregistic — the prediction market for global trade.
Freight rates, chokepoints, ports and tariffs as dated, settleable contracts.

Built by Chainova Technology Limited, Hong Kong, on DEXBuilder infrastructure.

All prices, order books and volumes on the site are simulated demonstration
data generated in the visitor's browser. Pregistic is pre-launch and is not
operating a trading venue.

No build step: plain HTML, CSS and browser JavaScript.
